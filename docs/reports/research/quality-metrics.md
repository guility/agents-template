# Сравнение инструментов качества и метрик

**Контекст:** [Wayfinder #17](https://github.com/guility/agents-template/issues/17). Срез `agents-template` — `f4b9a55`; языковые правила — закрепленные теги из [`fetch_language_templates.sh`](https://github.com/guility/agents-template/blob/main/scripts/setup/fetch_language_templates.sh).

## Вывод

Оставить общий CI-слой из **Lizard + Gitleaks + Semgrep + Trivy**, закрепить версии и одну конфигурацию на GitHub Actions и GitLab CI. Линт, покрытие и мутации запускать средствами языка. Сейчас workflow проверяют сложность/безопасность, но не запускают документированные linters; ряд сканеров пропускается при отсутствии бинарника, а языковые аудиты заканчиваются `|| true`. GitHub и GitLab используют разные версии Gitleaks/Semgrep. Gitleaks `detect` устарел, а текущий [pre-commit hook](https://github.com/guility/agents-template/blob/main/.hooks/pre-commit) передаёт нераспознаваемый `--staged`; используйте `git`/`dir` или `git diff --cached | gitleaks stdin`. [Security script](https://github.com/guility/agents-template/blob/main/scripts/common/security-scan.sh), [GH security workflow](https://github.com/guility/agents-template/blob/main/.github/workflows/security-scan.yml), [GitLab SAST jobs](https://github.com/guility/agents-template/blob/main/.gitlab/ci/sast.yml), [complexity script](https://github.com/guility/agents-template/blob/main/scripts/common/complexity-check.sh), [Gitleaks CLI](https://github.com/gitleaks/gitleaks).

## Стек по метрикам

| Область | Общая рекомендация | Python | Node.js / TypeScript | Rust | Go | C# |
|---|---|---|---|---|---|---|
| Быстрый lint/format | Языковой инструмент; версия и конфиг фиксируются в репозитории | Ruff check/format заменяет Black, isort и Flake8; оставить mypy для типов | ESLint + typescript-eslint, `tsc --noEmit`, Prettier check | `cargo fmt --check`; `cargo clippy --all-targets --all-features -- -D warnings` | `gofmt -d` + `golangci-lint` | `dotnet format --verify-no-changes` + Roslyn analyzers; фиксировать AnalysisLevel |
| Сложность | Lizard, CCN на функцию, порог 10; экспортировать CSV | То же | То же | То же | То же | То же |
| Секреты | Gitleaks, сканировать историю и рабочее дерево; сохранять redacted JSON/SARIF | То же | То же | То же | То же | То же |
| SAST | Semgrep с ревьюемым и версионируемым ruleset; SARIF 2.1.0 | Общий ruleset | Общий ruleset | Общий ruleset | Общий ruleset | Общий ruleset |
| Зависимости | Trivy по lock-файлам + CycloneDX SBOM; оставить специализированную проверку только для полезного дополнительного сигнала | `uv.lock` поддержан | pnpm/yarn/npm lock-файлы поддержаны | `Cargo.lock` поддержан | `go.mod` поддержан; govulncheck — опционально для reachability | `packages.lock.json` поддержан |
| Unit coverage | Одно Cobertura XML на компонент плюс исходный формат каждого инструмента | pytest-cov / coverage.py: lines + branches | Jest/Istanbul: lines + branches | cargo-llvm-cov: lines; branch coverage требует nightly | `go test -coverprofile` / `go tool cover`: statements | Coverlet collector: Cobertura; lines + branches |
| Mutation | Сохранять отчёт инструмента и число мутантов каждого статуса; сравнивать только компоненты с версией инструмента и ruleset | mutmut (не ставить cosmic-ray параллельно) | StrykerJS с Jest runner | cargo-mutants | Gremlins только как закреплённый пилот: 0.x, долго на больших модулях | Добавить Stryker.NET (требует .NET 10 runtime); его сейчас нет в [suite dispatch](https://github.com/guility/agents-template/blob/main/scripts/common/test-runners/suite-dispatch.sh) |

Языковые рекомендации следуют текущим пакетам, но сводят дублирующие варианты к одному основному инструменту: [Python](https://github.com/guility/agents-template-langs/blob/0f3b00b225c0c617f2954958f3a7b4f25418a8db/AGENTS.md), [Node.js](https://github.com/guility/agents-template-langs/blob/31fa7f67b4524ca9faebd662a4c86ab633953ed5/AGENTS.md), [Rust](https://github.com/guility/agents-template-langs/blob/360c6dc76e2935657c02cb0b47c5a96db9c9783f/AGENTS.md), [Go](https://github.com/guility/agents-template-langs/blob/d5547a7a264c1c6a69ab23810ad722f598156c66/AGENTS.md), [C#](https://github.com/guility/agents-template-langs/blob/8677ba3eb2730f2d5db28821bf6bbc0bd5ae9e03/AGENTS.md).

Основные источники: [Ruff](https://docs.astral.sh/ruff/) заменяет несколько Python lint/format инструментов; [mypy](https://mypy.readthedocs.io/en/stable/) остаётся отдельной проверкой типов; [typescript-eslint](https://typescript-eslint.io/docs/) отделяет ESLint-анализ TS от `tsc`; [Clippy](https://doc.rust-lang.org/stable/clippy/usage.html), [golangci-lint](https://golangci-lint.run/docs/welcome/quick-start/) и [.NET analyzers](https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/overview) документируют native lint. [Lizard](https://github.com/terryyin/lizard) поддерживает все пять языков и выдаёт CCN, но использует частичные парсеры: не трактовать среднюю CCN между языками как рейтинг. [Semgrep supported languages](https://docs.semgrep.dev/supported-languages) включает все пять, с неодинаковым объёмом правил/анализа. [Trivy language support](https://trivy.dev/docs/latest/coverage/language/) подтверждает lock-файлы из таблицы; [Trivy reporting](https://trivy.dev/docs/latest/guide/configuration/reporting/) описывает JSON/SARIF/SBOM. Для Go reachability дополнительно полезен [govulncheck](https://go.dev/doc/security/vuln/).

## Компонент × метрика: данные и представление

| Метрика | Источник, единица | GitHub Actions / GitLab CI и предел сравнения |
|---|---|---|
| Lint | JSON/SARIF от инструмента; `errors`, `warnings` на компонент | Step summary + артефакт. Числа между языками не сопоставлять: правила различаются. |
| Complexity | Lizard CSV; `CCN/function`, `max CCN`, число функций `CCN > 10` | Артефакт + CI status. Порог унифицирован, но частичный парсер и грамматики ограничивают сравнение. |
| Secrets | Gitleaks JSON/SARIF; число redacted findings по rule/severity | GH SARIF upload; GL SARIF artifact при доступном ingestion. Никогда не публиковать найденный секрет; Gitleaks поддерживает JSON/SARIF и redaction. |
| SAST / dependencies | Semgrep / Trivy SARIF 2.1.0; findings по severity, rule/CVE; Trivy дополнительно CycloneDX | GH code scanning принимает сторонний SARIF. GitLab SARIF ingestion — Ultimate; лимит отчёта 10 MB, 5,000 results/run. Для остальных тарифов оставлять JSON/SARIF артефактом. |
| Unit coverage | Cobertura XML + исходный профиль; `line_pct=covered/valid`, отдельно `branch_pct` и числитель/знаменатель | GL Cobertura-аннотации только для изменённых строк; badge читает отдельный regex из job log и может расходиться с XML. GL поддерживает badge на job; GH native status badge показывает только pass/fail. Вывод из штатных источников: Go coverage сообщает statement coverage, а cargo-llvm-cov branch coverage требует nightly, поэтому единой branch метрики для стабильного toolchain нет — показывать `n/a`, не подменять её line %. |
| Mutation | Нативный JSON/HTML либо сырой отчёт; tool score %, killed/survived/timed-out/uncovered/unviable counts | Job status + скачиваемый артефакт. Score не сравнивать без одинаковых операторов и правил исключения equivalent/unviable мутантов; GitLab/GitHub не дают общей mutation badge. |

Собирать `quality-metrics.json` с `schema_version`, `commit`, `component`, `metric`, `value`, `unit`, `numerator`, `denominator`, `tool/version`, `config_hash`, ссылкой на исходный отчёт и временем. Badge-матрица: GitHub — статус обязательного quality workflow; GitLab — pipeline badge и отдельный coverage badge по job-компоненту. Для lint, complexity, secrets, SAST, SCA и mutation показывать компоненты в JSON/HTML-отчёте, а не придумывать сводный процент.

Платформенные ограничения: [GitHub status badge](https://docs.github.com/en/actions/how-tos/monitor-workflows/add-a-status-badge) — состояние workflow; [GitHub SARIF upload](https://docs.github.com/en/code-security/how-tos/find-and-fix-code-vulnerabilities/integrate-with-existing-tools/upload-sarif-file) — результаты сторонних сканеров. [GitLab coverage](https://docs.gitlab.com/ci/testing/code_coverage/) разделяет regex-процент и Cobertura/JaCoCo-аннотации; [GitLab badges](https://docs.gitlab.com/user/project/badges/) могут выбрать job; [GitLab SARIF](https://docs.gitlab.com/user/application_security/detect/sarif/) поддерживает Semgrep/Trivy-подобные SARIF, но доступен на Ultimate.

Покрытие подтверждено [coverage.py branch measurement](https://coverage.readthedocs.io/en/latest/branch.html) и [Cobertura XML](https://coverage.readthedocs.io/en/latest/commands/cmd_xml.html), [Jest reporters/thresholds](https://jestjs.io/docs/configuration), [cargo-llvm-cov Cobertura и nightly branch caveat](https://github.com/taiki-e/cargo-llvm-cov), [Go statement coverage](https://go.dev/blog/cover), [Coverlet Cobertura](https://github.com/coverlet-coverage/coverlet). Мутационные источники: [mutmut](https://mutmut.readthedocs.io/en/latest/), [StrykerJS JSON](https://stryker-mutator.io/docs/stryker-js/configuration/), [cargo-mutants statuses](https://mutants.rs/using-results.html), [Gremlins maturity/runtime limits](https://github.com/go-gremlins/gremlins), [Stryker.NET reporters](https://stryker-mutator.io/docs/stryker-net/reporters/), [Stryker.NET prerequisites](https://stryker-mutator.io/docs/stryker-net/getting-started/).

## Приоритет

Оставить Lizard, Gitleaks, Semgrep, Trivy и native coverage; убрать дубли advisory-сканеров (Safety/pip-audit, npm/yarn audit, cargo-audit, `dotnet list --vulnerable`) из общего гейта после проверки покрытия lock-файлов Trivy; оставить cargo-deny только для явной license policy. Оставить govulncheck для Go reachability. Заменить пропускающие проверки на fail-closed (нет инструмента/отчёта = ошибка), унифицировать зафиксированные версии и ruleset. Добавить реальные lint и C# mutation jobs; поправить пути/форматы coverage; сделать raw и нормализованный отчёты обязательными артефактами. Не заявлять одинаковую 100% branch coverage для Go и Rust stable на основании имеющихся штатных профилей.
