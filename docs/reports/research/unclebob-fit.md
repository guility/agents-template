# Uncle Bob repository fit for the five language packs

**Context:** [Wayfinder issue #15](https://github.com/guility/agents-template/issues/15). Checked 2026-11-20. No product code changed.

## Recommendation

Keep APS as a reference only until its license is clarified; if cleared, its language-neutral Gherkin contract can guide acceptance tests. Treat Mutator and Dryer as experimental external CLIs behind adapters; neither is ready to replace the required per-language CI runners. Exclude SCRAP from these packs. Keep AgNesse out of the default template: it is a separate Java wiki and Slim harness, not a library.

## Repository evidence

- **SCRAP** — JVM Clojure CLI, <code>clj -M:scrap &lt;spec-path&gt;</code>; JSON, verbose, and baseline/compare options. It parses and scores Speclj <code>describe/context/it</code> specs, so it has no Python/TS/Rust/Go/C# input API. <code>deps.edn</code> pins Clojure 1.12.0, data.json 2.5.1, tools.reader 1.4.2; Speclj 3.10.0 is a test alias. No LICENSE or declared GitHub license; no tags/releases; 9 commits, latest 2026-03-17. - **Dryer** — Python 3.11+ CLI for structural duplicate candidates in Clojure, Java, Go, TypeScript, Rust, and Python; no C#. It emits a Jaccard-similarity report (default threshold 0.82) and <code>.metrics/dry.edn</code>; a report is advisory and exits successfully even when candidates exist. Declared dependencies are only <code>tree-sitter&gt;=0.24</code> and <code>tree-sitter-language-pack&gt;=0.7</code> (pytest is dev-only); dry4clj is an algorithm reference, not a package dependency. Ranges are unpinned and there is no lock. The parser setup calls <code>download([language])</code>; the language-pack docs say parsers download on first use and cache locally, so offline CI must pre-cache them. 0BSD; version 0.1.0, no tag/release; last pushed 2026-10-03. ## Fit by pinned language pack

SCRAP is excluded for every pack: it only understands Speclj/Clojure specs, and its license is undeclared.

- [Python <code>python/v2.0.0</code> rules](https://github.com/guility/agents-template-langs/blob/0df2dbc336e0f629fc994aeb033289f0b5e1a5fa/AGENTS.md): Mutator only through a wrapper and after adding/pinning its Python + crapper toolchain; keep <code>mutmut</code> or <code>cosmic-ray</code> as the named option. Dryer can be an optional, non-gating report wrapper. If APS licensing is cleared, add Python generator/runtime/runner code. AgNesse is an optional Slim bridge, not the default.
- [Node.js/TypeScript <code>nodejs/v1.0.1</code> rules](https://github.com/guility/agents-template-langs/blob/48bad615bd49a3cbc9fb154cdf9f0abdd23e67c6/AGENTS.md): Mutator wrapper only; keep Stryker as the required mutation tool. Dryer is an optional report wrapper. If APS licensing is cleared, add generated tests and a Node runner adapter. AgNesse requires a custom Slim server.
- [Rust <code>rust/v1.0.1</code> rules](https://github.com/guility/agents-template-langs/blob/fd6b7fa44f2183660ca1878c338b7e303c59f17e/AGENTS.md): Mutator wrapper only; keep <code>cargo-mutants</code> as the required mutation tool. Dryer is an optional report wrapper. If APS licensing is cleared, add Rust-generated tests and a runner adapter. AgNesse requires a custom Slim server.
- [Go <code>go/v1.0.1</code> rules](https://github.com/guility/agents-template-langs/blob/4a77908763503640ea51d66621e014c17e31ddfd/AGENTS.md): Mutator wrapper only; the Go pack says to choose a supported Go mutation tool but does not name one. Dryer is an optional report wrapper. If APS licensing is cleared, its Go parser/mutator fallback can run directly, but still needs project generator/runtime/runner code. AgNesse requires a custom Slim server.
- [C# <code>csharp/v1.0.2</code> rules](https://github.com/guility/agents-template-langs/blob/8677ba3eb2730f2d5db28821bf6bbc0bd5ae9e03/AGENTS.md): Exclude Mutator and Dryer because neither supports C#. Use Stryker.NET for mutation. If APS licensing is cleared, use its spec with .NET-generated tests/runner. Exclude AgNesse by default; a custom Slim server is possible but adds an unrelated Java service and CPL-1.0 review.

All adapter decisions remain subordinate to [template requirements](../../../AGENTS.md): mandatory test runners, 100% applicable mutation score, locked dependencies, and the two-mutants-per-method rule. Pin the external toolchain and its license before any implementation decision.
